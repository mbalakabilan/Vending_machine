# Vending_machine
# Vending Machine

## Description
A simple vending machine designed using Verilog HDL.

## Features
- ₹5 coin input
- ₹10 coin input
- Product output
- ₹5 change output
- Reset
- FSM-based desig
- product price 5

## Files

### vending_machine.v
Main vending machine Verilog design.

### tb_vending.v
Testbench used to simulate and verify the vending machine.

## Tools Used
- Verilog HDL
- ModelSim
